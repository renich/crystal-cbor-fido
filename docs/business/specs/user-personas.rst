Primary Stakeholders
--------------------

* **FIDO2 / WebAuthn Protocol Engineer**: Requires deterministic CBOR serialization and strict canonical validation for COSE keys, attestation statements, and CTAP2 authenticator messages.
* **Security & Cryptography Auditor**: Requires transparent bounds checking, :math:`O(1)` streaming map key order verification, 128-bit underflow-safe negative integer decoding, and zero C-binding memory hazards.
* **Autonomous AI Coding Agent**: Requires unambiguous module contracts, strongly-typed ``Crystal::Cbor::Fido::Value`` unions, structured exception hierarchies, and zero-suppression static analysis gates.
